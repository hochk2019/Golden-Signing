## 2. Kiến trúc (đồng bộ bản gốc §3, map vào code thật)

```text
UI (PySide6)
  → Workflow orchestrator (mở rộng BatchEngine/worker)
      → ConversionManager (MSOfficeProvider | LibreOfficeProvider)
      → Preflight (pdf/inspection.py hiện có)
      → CompressionManager (analyzer + tiers + target)
      → Signing Core (token_pdf_signer / pus_safe — KHÔNG sửa nếu không cần)
      → Verify → atomic commit → history
```

- UI không gọi COM/qpdf trực tiếp  
- Extension chỉ là gợi ý; check magic/header khi có thể  
- Temp workspace dưới `%LOCALAPPDATA%\GoldenSign\workspace\` (dọn khi start)

**Office (máy bạn có MS Office):**

1. Detect Word/Excel COM  
2. `ExportAsFixedFormat` (Word/Excel) — không macro, không lưu đè source  
3. Close app instance cẩn thận; timeout; không song song nhiều instance  
4. Fallback LibreOffice nếu COM fail  
5. Validate PDF đầu ra  

**Nén:**

- Spike so sánh trên file thật (kể cả empty-password nếu có)  
- Chốt engine trong `ADR-compression.md`  
- PUS Safe: target unsigned ≈ 400KB − reserve (mặc định 32KB)  
- File đã có signature → chặn/cảnh báo

## 5. Definition of Done (rút gọn bản gốc §37)

- Office convert OK trên máy có MS Office; source không đổi  
- 3–4 preset nén + custom + ghi nhớ  
- Nén trước ký; verify chữ ký vẫn pass  
- Golden sample + empty-password regression  
- Batch: 1 file lỗi không hỏng cả queue  
- UI không freeze; error dễ hiểu  
- License report; install/update test; release asset + checksums  
- PUS upload **user** xác nhận (không claim trước)
