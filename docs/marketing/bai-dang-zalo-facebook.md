**Bạn đã quen với ECUSTOOL khi ký số hồ sơ?**

ECUSTOOL vẫn là lựa chọn phổ biến cho quy trình ký số — nhiều anh chị làm thủ tục hải quan đã dùng quen tay.

Nếu bạn muốn **một làn gió mới**, chuyên sâu cho **ký PDF hàng loạt**, **Word/Excel → PDF** và **nén file trước khi ký** (đỡ khổ vì file quá lớn), có thể thử **Golden Sign** — phiên bản **1.1.2**.

**Golden Sign hợp với ai?**

• Ký **nhiều file một lần** (PDF / Word / Excel) — kéo thả vào danh sách, file lỗi không làm hỏng cả batch  
• **Word, Excel tự chuyển sang PDF** rồi ký (cần Microsoft Office trên máy)  
• **Nén PDF trước khi ký** — preset *PUS Safe ≤400 KB* / *Cân bằng* / *Lossless*; hiện rõ **gốc → sau nén**  
• Nút **CHỈ NÉN** (không ký) → sau đó bấm **KÝ SỐ** để ký file đã nén  
• File PDF **mã hóa “empty password”** — nhiều công cụ khác mở/ký không được  
• Vẫn dùng **USB token** (PKCS#11) quen thuộc — chọn chứng thư theo doanh nghiệp, nhập PIN, **không lưu PIN**  
• Chữ ký **hiển thị** (tên công ty, MST…) hoặc **vô hình** — hồ sơ lưu theo từng chứng thư  
• Lịch sử ký, kiểm tra file đã ký, **cập nhật tự động** từ GitHub (có thanh tiến trình)

## Bài Zalo cá nhân / nhóm (dài vừa)

**Golden Sign 1.1.2** — app ký số PDF cho anh chị làm hồ sơ / hải quan.

Đã quen ECUSTOOL? Có thể dùng thêm app này cho các việc **ECUSTOOL không tối ưu**:

1. **Ký hàng loạt** — kéo cả folder PDF/Word/Excel vào, bấm một nút  
2. **Word/Excel → PDF → ký** tự động (có MS Office là được)  
3. **Nén trước khi ký** — file scan >500KB có thể xuống ~300–400KB (preset PUS Safe)  
4. **CHỈ NÉN** rồi **KÝ SỐ** tiếp — 2 bước riêng, trạng thái rõ ràng  
5. USB token như bình thường; **không lưu PIN** trên máy
