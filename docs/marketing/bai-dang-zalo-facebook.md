**Bạn đã quen với ECUSTOOL khi ký số hồ sơ?**

ECUSTOOL vẫn là lựa chọn phổ biến cho quy trình ký số — nhiều anh chị làm thủ tục hải quan đã dùng quen tay.

Nếu bạn muốn **một làn gió mới**, chuyên sâu cho nhu cầu **ký PDF hàng loạt** và một số tình huống file “khó nhằn”, có thể thử **Golden Sign** (phiên bản 1.0.0).

**Golden Sign hợp với ai?**
• Ký **nhiều PDF một lần** (cả folder) — file lỗi không làm hỏng cả batch  
• File PDF **mã hóa kiểu “empty password”** (không phải mật khẩu do bạn đặt) — nhiều công cụ khác mở/ký không được  
• Vẫn dùng **USB token** (PKCS#11) quen thuộc — chọn chứng thư theo doanh nghiệp, nhập PIN, không lưu PIN  
• Chữ ký **hiển thị** (tên công ty, MST, logo…) hoặc **vô hình** — profile lưu theo từng chứng thư  
• Lịch sử ký, kiểm tra file đã ký, cập nhật tự động từ GitHub  

**Cài nhanh:** 1 file Setup → double-click → Desktop shortcut → chạy.  
**Phiên bản:** 1.0.0 · Windows 10/11  
**Tải:** https://github.com/hochk2019/Golden-Signing/releases  

Ứng dụng **phi lợi nhuận**, hỗ trợ anh chị làm hồ sơ — không thay thế quy định của cơ quan, CA hay hệ thống tiếp nhận. Kết quả nhận hồ sơ phụ thuộc hệ thống đích.
